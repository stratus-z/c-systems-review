# C语言系统级编程复习网站与资料库

从 `课件/` 中的 7 份 PDF（共 686 页）系统整理的知识点、练习题库与往年真题/模拟卷集合。全部资源均使用相对路径，不依赖外网或额外 npm 依赖，克隆或解压后即可在其他电脑上一键启动。

## 一键启动网站

**Windows（推荐，一键启动）：**
- 双击根目录下的 [`启动复习网站.cmd`](启动复习网站.cmd)：
  - 若本机已安装 Node.js（自动查找 `PATH`、`%ProgramFiles%\nodejs` 或 `%LOCALAPPDATA%\Programs\nodejs`），将启动本地只读服务并自动在浏览器打开 `http://127.0.0.1:8765/`，改善 PDF 内嵌跳页与本地存储稳定性；关闭黑色终端窗口或按 Ctrl+C 即停止服务。
  - 若本机未安装 Node.js，脚本会自动用默认浏览器直接打开离线版 [`复习网站/index.html`](复习网站/index.html)，仍可完整检索知识点、刷题、做模拟卷和查看原课件 PDF。

**macOS / Linux：**
- 若已安装 Node.js，在仓库根目录运行 `node server.cjs --open` 启动本地服务并打开浏览器。
- 未安装 Node.js 时，直接用浏览器打开 [`复习网站/index.html`](复习网站/index.html) 即可离线使用。

> 重复启动提示端口占用时，请先关闭先前运行的终端窗口后再启动。学习进度保存在当前浏览器的本地存储中，`file://` 与 `http://127.0.0.1:8765/` 两者的记录相互独立，可在「我的复习记录」页面导出/导入 JSON 备份迁移。

## 功能模块

- **知识点手册：** 按第 1–7 课与主题分类全文检索 191 个核心知识点，支持收藏、掌握标记、单页打印，以及点击出处直达原课件 PDF 物理页。
- **练习与组卷：** 555 道分层练习题（单选、多选、判断、简答、代码分析），支持按课次/难度/题型/知识点筛选与逐题或模拟组卷模式。
- **往年题与模拟卷：** 收录 2025 秋季期末回忆全卷与 3 套全真对标模拟卷（每卷 44 题：30 单选 + 10 简答 + 4 问答），支持整卷浏览/一键展开答案、逐题练习、模拟考试、错题重练与评分要点对照。
- **课件页码索引与我的复习记录：** 686 页原课件逐页索引、错题统计与 JSON 学习记录备份导出/导入。

## 仓库目录说明

- `复习网站/`：纯静态网站前端与内置数据（`index.html`、`styles.css`、`app.js`、`data.js`）。
- `课件/`：7 份原始课程 PDF 课件（网站页码跳转与 Markdown 链接直接引用该目录）。
- `C语言系统级编程知识点汇总.md`：完整知识点与规范差异汇总（可在网页内一键下载）。
- `题库及参考答案.md`：全部 555 道分层练习题及参考答案、评分要点与解析。
- `往年题与模拟卷及参考答案.md`：往年回忆卷与 3 套模拟卷完整题目、参考答案与解析（可在网页内一键下载）。
- `启动复习网站.cmd` / `server.cjs`：跨电脑一键启动脚本与零依赖本地静态服务器。
